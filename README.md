# 🧠 Data Structures & Algorithms Specialization (UCSD – Coursera)

## 📘 Course Overview
This repository contains my study notes, code implementations, and challenge solutions from the "Data Structures & Algorithms Specialization" offered by the University of California San Diego (UCSD) on Coursera.  
This six‑course series dives into key algorithmic programming techniques frequently used in software engineering, data science, and technical interviews.

## 🔗 Course Link
[Data Structures & Algorithms Specialization – Coursera](https://www.coursera.org/specializations/data-structures-algorithms)

## 🧠 Topics Covered
- Fundamental data structures: stacks, queues, linked lists, trees  
- Algorithmic techniques: divide & conquer, greedy algorithms, dynamic programming  
- Graph algorithms: BFS, DFS, shortest paths, spanning trees  
- String algorithms & pattern matching  
- Advanced algorithmic principles: network flows, streaming algorithms, complexity issues
